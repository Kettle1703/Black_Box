# Black_Box («Буквоед»)

Учебная настольная игра для школьников, построенная на модели «чёрного ящика».

Пользователь подаёт на вход числа или русские слова, наблюдает результат преобразования и по серии опытов пытается определить скрытое правило. После изучения алгоритма можно пройти автоматически сформированный экзамен и проверить своё предположение.

> **Статус проекта:** завершённый командный учебный проект. Приложение разработано для Windows на C#/.NET 6 и WPF.

## Идея проекта

«Чёрный ящик» — это система, внутреннее устройство которой неизвестно пользователю. Известны только входные данные и полученный результат.

В приложении предусмотрено 29 алгоритмов преобразования, заданных преподавателем. Пользователь выбирает алгоритм, проводит опыты, сохраняет результаты в дневнике и затем проходит экзамен по выбранному правилу.

## Возможности

- выбор одного из 29 алгоритмов преобразования;
- работа с числовыми и строковыми входными данными;
- проведение неограниченного количества опытов;
- автоматическое сохранение результатов в дневник;
- генерация экзамена из пяти заданий;
- автоматическая проверка ответов;
- сохранение состояния незавершённого экзамена при переходе между разделами;
- встроенный калькулятор арифметических выражений;
- проверка корректности скобочной последовательности;
- соблюдение приоритета умножения и деления;
- таблица русского алфавита;
- справка и горячие клавиши для навигации.

## Калькулятор

Встроенный калькулятор поддерживает арифметические выражения и выполняет предварительную проверку введённой строки:

- допустимость символов и операторов;
- корректность скобочной последовательности;
- отсутствие пустых скобок;
- обработка приоритета операций;
- проверка деления на ноль;
- подстановка порядковых номеров букв русского алфавита.

В рамках проекта деление выполняется нацело либо запрещается, если результат не соответствует правилам приложения.

## Структура приложения

Основные разделы:

| Раздел | Назначение |
|---|---|
| `Алгоритмы` | выбор скрытого правила преобразования |
| `Опыты` | ввод данных и получение результата |
| `Дневник` | сохранение истории проведённых опытов |
| `Экзамен` | генерация заданий и проверка ответов |
| `Калькулятор` | вычисление и проверка арифметических выражений |
| `Алфавит` | вспомогательная таблица русского алфавита |
| `Информация` | справка и список горячих клавиш |

## Сборка и запуск

### Visual Studio

1. Откройте файл решения `.sln`.
2. Дождитесь восстановления NuGet-пакетов.
3. Выберите конфигурацию `Debug` или `Release`.
4. Запустите проект.

### Командная строка

Из каталога проекта выполните:

```bash
dotnet restore
dotnet build
dotnet run
```

## Публикация

Проект настроен для публикации под Windows x64.

```bash
dotnet publish -c Release -r win-x64 --self-contained true
```

Результат публикации будет находиться в каталоге:

```text
bin/Release/net6.0-windows/win-x64/publish/
```

## Управление

Общие горячие клавиши:

| Сочетание | Действие |
|---|---|
| `Ctrl + 1` | алгоритмы |
| `Ctrl + 2` | опыты |
| `Ctrl + 3` | экзамен |
| `Ctrl + 4` | дневник |
| `Ctrl + 5` | калькулятор |
| `Esc` | возврат в меню |

В полях ввода клавиша `Enter` запускает основное действие текущего раздела.

## Ограничения

- приложение работает только в Windows;
- алгоритмы преобразования были заданы в учебном задании;
- поддерживаются русские буквы и предусмотренные проектом числовые форматы;
- архитектура отражает уровень раннего учебного командного проекта;
- автоматические модульные тесты отсутствуют.
